# Quarkus Coding Harness Template

Template interno para iniciar aplicações Java 25 com Quarkus LTS e Maven, já acompanhadas por um harness de desenvolvimento orientado a agentes e por checkpoints humanos.

O repositório está na fase de desenho e planejamento. Nenhum código de aplicação ou tooling executável foi implementado ainda.

## Comece por aqui

1. Leia o [goal do template](goals/template-harness/goal.md) e a [especificação aprovada](specs/template-harness/spec.md).
2. Revise a [arquitetura proposta](doc/arquitetura/arquitetura-harness.md) e o [índice de ADRs](doc/adr/README.md).
3. Revise o [plano](tasks/plan.md) e o [checklist](tasks/todo.md).
4. A implementação de `AGENTS.md`, build Quarkus, feature neutra e harness Sonar começará somente após novo GO humano.
