# Quarkus Coding Harness Template

Template interno para iniciar aplicações Java 25 com Quarkus LTS e Maven, já acompanhadas por um harness de desenvolvimento orientado a agentes e por checkpoints humanos.

O repositório está na fase de especificação. Nenhum código de aplicação ou tooling executável foi implementado ainda.

## Comece por aqui

1. Leia a [especificação do template](specs/template-harness/spec.md).
2. Revise as questões em aberto e os critérios de aceitação.
3. Somente após aprovação humana serão elaborados a arquitetura detalhada, os ADRs propostos, o plano e o checklist de implementação.
